# Tally

只保存在你 iPhone 上的私密记账本。记录支出和收入，支持多币种（汇率每天更新）、统计图表、月度预算、面容 ID 解锁和 ICA Banken 账单导入。界面有中英文和深浅色模式，还有五套主题可选：港湾、账簿、小票、存钱罐、金币。

网址：<https://haojielo.github.io/tally/>

## 安装到 iPhone

1. 用 **Safari** 打开上面的网址，点“分享”，选 **添加到主屏幕**。
2. 以后都从主屏幕上的 Tally 图标打开。
3. 打开 Tally → 设置 → 安全，开启 **面容 ID 解锁**。按提示先设一个 6 位备用密码，再用面容 ID 确认。

需要 iOS 16.4 或更新版本。

## 数据存在哪里

- 记录存在 iPhone 上这个 App 自己的存储里（IndexedDB），不在 GitHub 上，也不在任何服务器上。设置 → 账单与数据 → “数据存放位置”会显示当前用的是哪一份，以及有没有开启长期保存。
- 主屏幕上的 Tally 和在 Safari 里打开的同一网址各存一份数据，两边互不相通，这是苹果的设计。请始终从主屏幕图标打开。Safari 里的数据还可能在很久没访问后被清理。
- **删除主屏幕图标会把数据一起删掉**。换手机、重置手机时数据也不会自动跟过去。请定期在设置里导出加密备份，存到“文件”或 iCloud 云盘，需要时用“从备份恢复”。
- 版本更新只替换程序文件，不会动你的记录。打开 App 时如果有新版本会自动切换；App 一直开着时会显示“新版本已就绪”，点“重新载入”即可。
- 开启面容 ID 后，“密码”App 里会多一个 Tally 的通行密钥。不要删除它，否则只能用备用密码解锁。

## 货币

- 只有一个“货币”设置：点首页月度卡片右上角的币种，或者在设置 → 货币与汇率里选瑞典克朗、人民币、美元、欧元或其他币种。
- 记一笔时默认就用这个货币。偶尔要记别的币种，点金额左边的币种按钮切换即可。
- 合计、统计和预算都用这个货币显示。其他币种的记录按记账当天的汇率换算，原来的金额会保留，所以合计总是等于每一行加起来。
- 预算按设置时的货币保存，切换货币后按最新汇率换算显示，下次修改预算时会改存为当前货币。

## 主题和图标

- 设置 → 外观 → 配色，随时可以切换，深色和浅色模式都有对应的配色。
- 保存一笔、导入完成或输入有误时，手机会轻轻震一下。这需要 iOS 18 或更新版本，不想要的话可以在设置 → 外观 → 触感反馈里关掉。
- 动画都很短，只在你操作之后出现。如果在 iPhone 的“设置 → 辅助功能 → 动态效果”里打开了“减弱动态效果”，Tally 会改用淡入淡出。
- 主屏幕图标在“添加到主屏幕”的那一刻就固定了。想换图标：先导出加密备份 → 用 Safari 打开网址，在设置里选好图标 → 添加到主屏幕 → 在新图标里恢复备份 → 确认没问题后删除旧图标。备份里也会记住你选的主题和图标。

## 导入 ICA Banken 账单

- 在电脑浏览器登录 ICA Banken 网银（手机 App 没有导出功能），进入 Konton，打开账户，把交易列表导出为 CSV 或 Excel 文件。
- 找不到导出按钮时，可以在 Dokument → Konton 下载 PDF 月结单，或者直接选中网页上的交易列表复制下来，在 Tally 里用“粘贴文本”导入。
- 导入时会自动识别账单的货币（币种列、金额旁的 kr、€、¥ 等符号、表头或“Currency: …”这样的说明）。认不出来时会请你先选好币种再导入。表格里每一行写了不同币种的（比如 Revolut），会按每一行自己的币种导入。
- 识别全部在手机上完成。转账、未入账和可能已经记过的交易默认不勾选。已经导入过的交易会自动跳过，换一种格式重新导入也不会重复。
- 某个商户的分类改过一次以后，再导入这个商户时会自动用你选的分类。

## 隐私

- 没有服务器、没有账号，也没有任何统计或追踪代码。
- 唯一的网络请求是从 frankfurter.dev 获取汇率，请求里只有币种代码。
- 面容 ID 由 iPhone 系统验证（WebAuthn 通行密钥），Tally 拿不到任何面容数据。
- 加密备份使用 AES-256-GCM 加密，密钥由你的备份密码经 PBKDF2 运算 31 万次得到，密码本身不会保存在任何地方。
- 解锁保护的是打开 App 这一步。数据存放在 iOS 给这个 App 单独隔离的存储里，iPhone 锁屏时由系统加密。
- 这个仓库是公开的，里面只有程序代码，你的账目永远不会出现在这里。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` `app.js` `styles.css` | 应用本体 |
| `sw.js` | 离线缓存，没网也能打开 |
| `manifest.webmanifest` 和 4 个 `.png` 图标 | 主屏幕图标与名称 |
| `pdf.min.js` `pdf.worker.min.js` | Mozilla pdf.js（Apache-2.0 许可），只在导入 PDF 对账单时加载 |
| `stream-polyfill.js` `pdf.worker.shim.js` | 补上 iPhone Safari 缺少的功能，让 PDF 导入在 iPhone 上也能运行 |
| `icons/` | 五套主题各自的主屏幕图标 |
| `.nojekyll` | 让 GitHub Pages 原样发布这些文件 |

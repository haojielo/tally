# Tally

只保存在你 iPhone 上的私密记账本。记录支出和收入，支持多币种（主货币 SEK，汇率每天更新）、统计图表、月度预算、面容 ID 解锁和 ICA Banken 账单导入，界面有中英文和深浅色两种模式。

网址：<https://haojielo.github.io/tally/>

## 安装到 iPhone

1. 用 **Safari** 打开上面的网址，点“分享”，选 **添加到主屏幕**。
2. 以后都从主屏幕上的 Tally 图标打开。
3. 打开 Tally → 设置 → 安全，开启 **面容 ID 解锁**。按提示先设一个 6 位备用密码，再用面容 ID 确认。

需要 iOS 16.4 或更新版本。

## 重要提醒

- 数据只存在这台 iPhone 的 Tally 里。**删除主屏幕图标会把数据一起删掉**，请定期在设置里导出加密备份，存到“文件”或 iCloud 云盘。换手机时用“从备份恢复”。
- 主屏幕上的 Tally 和在 Safari 里打开的同一网址各存一份数据，两边互不相通。请始终从主屏幕图标打开。
- 开启面容 ID 后，“密码”App 里会多一个 Tally 的通行密钥。不要删除它，否则只能用备用密码解锁。
- 发布新版本后，下次打开 App 会提示“新版本已就绪”，点“重新载入”即可，数据不受影响。

## 导入 ICA Banken 账单

- 在电脑浏览器登录 ICA Banken 网银（手机 App 没有导出功能），进入 Konton，打开账户，把交易列表导出为 CSV 或 Excel 文件。
- 找不到导出按钮时，可以在 Dokument → Konton 下载 PDF 月结单，或者直接选中网页上的交易列表复制下来，在 Tally 里用“粘贴文本”导入。
- 识别全部在手机上完成。转账、未入账和可能已经记过的交易默认不勾选。已经导入过的交易会自动跳过，换一种格式重新导入也不会重复。
- 某个商户的分类改过一次以后，再导入这个商户时会自动用你选的分类。

## 隐私

- 没有服务器、没有账号，也没有任何统计或追踪代码。
- 唯一的网络请求是从 frankfurter.dev 获取汇率，请求里只有币种代码。
- 面容 ID 由 iPhone 系统验证（WebAuthn 通行密钥），Tally 拿不到任何面容数据。
- 加密备份使用 AES-256-GCM 加密，密钥由你的备份密码经 PBKDF2 运算 31 万次得到，密码本身不会保存在任何地方。
- 解锁保护的是打开 App 这一步。数据存放在 iOS 给这个 App 单独隔离的存储里，iPhone 锁屏时由系统加密。
- 这个仓库是公开的，里面只有程序代码，你的账目永远不会出现在这里。

## 文件

| 文件 | 作用 |
